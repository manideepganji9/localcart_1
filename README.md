# LocalCart 🛍️

### Discover. Buy. Sell. Locally.

LocalCart is a local-first marketplace designed to connect buyers with nearby sellers and help small local businesses create their own online storefront.

Instead of separating local discovery and local selling across multiple platforms, LocalCart brings the experience together in one place.

## 🚀 Version 1.0

This repository contains the first working version of LocalCart.

Version 1 focuses on the core marketplace experience:

- Buyer and Seller accounts
- Google authentication
- Buyer/Seller role-based dashboards
- Local store discovery
- Seller storefronts
- Product listings
- Product images
- Inventory management
- Low-stock tracking
- Shopping cart
- Order placement
- Atomic inventory updates
- Buyer ↔ Seller conversations
- Real-time chat
- Seller order management
- Buyer order tracking
- AI-powered LocalCart Assistant
- Seller AI Assistant
- Cloudinary image storage
- Firebase authentication and database
- Vercel production deployment

## 🎯 What LocalCart is trying to solve

Many local sellers have products and services but limited digital reach.

At the same time, customers often want to buy from nearby businesses but don't have an easy way to discover what is available around them.

LocalCart is built around this simple idea:

**Local sellers + Local products + Local buyers = LocalCart**

## 🔐 Security

LocalCart uses authenticated Firebase users and Firestore security rules to protect user, seller, product, order and conversation data.

Sensitive credentials are kept outside the public source code.
